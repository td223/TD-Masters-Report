\subsection{Navigation}

To demonstrate the robots ability to navigate an arbitrary path, a route was set up using 3D printed obstacles to simulate a path that a real world use case could need. The goal of the path was to show that fluid could be delivered through a channel in the silicon inner tube.

This path started shorted than the relaxed length of the actuator and so required the operator to pull on the silicon tube to retract the device before steering the device using the tendons.
